Projection Disclaimer:
All polygons are in projected georeferenced coordinates NOT pixel coordinates. Projection: EPSG:32631 - WGS 84 / UTM zone 31N - Projected


Vector Naming:
GT20sqm - Contains any building greater than or equal to 20 square meters in area.  All historical scoring for the challenge has been done using these data.  Any future scoring servers will be scored on these data.

All - Contains any building greater than or equal to 5 square meters in area.


Masks:
LowFidelityAnnotationMask - Contains areas where the annotations are outdated or suboptimal.  Ultimately only a few areas that are contained here, will let the end users decide if the data are worth masking.  Any future scoring will ignore on these areas.


Metadata:
SAR_orientations - 0 (North Facing), 1 (South Facing)
